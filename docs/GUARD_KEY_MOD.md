# Мод «Guard Key Names»: офицеры названы по ключу — как это устроено

> Дополнение к исследованию TE1Modding (см. `TE1ModdingPart1.zip`,
> `docs/EVENTS_BREAKTHROUGH.md`). Здесь — полный разбор механики
> «офицер ↔ ключ» и реализация мода, который автоматически переименовывает
> офицеров в цвет их ключа.

## 1. Ключи офицеров: жёсткая привязка

Ключ выяснен из **байткода событий** игры (фрейм `game`, дамп
`dumps/game_events.txt`, группа **#5363** `assign_keys`, офс 2389178):

```
ЕСЛИ  sys_cond-16("assign_keys")
ТО    act88("NPC_1_Inv_1", "0_100")    # офицер #1 → предмет 0  = Cell Key
ТО    act88("NPC_2_Inv_1", "7_100")    # офицер #2 → предмет 7  = Utility Key
ТО    act88("NPC_3_Inv_1", "6_100")    # офицер #3 → предмет 6  = Entrance Key
ТО    act88("NPC_4_Inv_1", "1_100")    # офицер #4 → предмет 1  = Staff Key
ТО    act88("NPC_5_Inv_1", "43_100")   # офицер #5 → предмет 43 = Work Key
```

Группа вызывается один раз при создании тюрьмы (`sys_act14("assign_keys", 1)`
из группы #446) и у неё **нет условий по карте** — расписание одинаковое
во всех тюрьмах и DLC (поэтому, например, в любом месте «4-й офицер = красный
ключ»). Формат значения `ID_прочность` (`0_100` = предмет ID 0 с прочностью 100).

Предметы из `items_eng.dat`:

| NPC | item ID | Name | Info (из игры) |
|:-:|---:|---|---|
| 1 | 0 | Cell Key | Unlocks **yellow** doors |
| 2 | 7 | Utility Key | Unlocks **orange** doors |
| 3 | 6 | Entrance Key | Unlocks **purple** doors |
| 4 | 1 | Staff Key | Unlocks **red** doors |
| 5 | 43 | Work Key | Unlocks **green** doors |

Связь «офицер #N ↔ NPC_N» подтверждена по `create_guards` (группы #449–#453):
каждый созданный `BASE - Guard[251]` получает `alterable[0] = (fastloop)+1`,
а инвентарь охрану достаёт этим же чтением `NPC_<n>_Inv_1` (группa #4370).
Офицеры #6 и дальше ключей НЕ получают (встречается в крупных тюрьмах).

## 2. Откуда берутся имена офицеров (пайплайн)

1. **Фрейм `names`** — игрок вводит своё имя/аватар.
2. **Фрейм `npc_rename`** — экран «население тюрьмы»:
   - цикл `empty_names` чистит `GuardName_1..20`, `InmateName_1..20`;
   - `cop_loop` (группы #110–#111): если `GuardName_<n>` пуст —
     `pull_name` тянет случайное имя из объекта-пула `Names[633]`;
     кнопка **mix** перетасовывает весь ростер;
   - клик по офицеру → ручное переименование (группы #124–#139);
   - глобальный объект **Named variable object** (в этом фрейме `obj_info=3`)
     хранит `GuardName_N`, `InmateName_N` — переменные переживают смену фрейма.
3. **Клик «start»** — группа **#15** (проверено для eur/rus/pol): единственное
   действие перехода `storyboard:act2(5)` во всём фрейме, значит до игры можно
   добраться только через неё. Никакого Enter-ярилинга нет.
4. **Фрейм `game`** — `create_guards` (группы #449–#453) называет стражников:
   `act49(alt_str 0) = "Officer " + GuardName_<n>`.
5. **Сейвы**: `save.dat` секция `Guards` сохраняет имя каждого охранника;
   `createLOAD_guards` (группа #454+) восстанавливает имена из сейва через
   `String tokenizer`. Загрузка сейва вообще не проходит фрейм `npc_rename`.

## 3. Что делает мод (инъекция в exe)

В группу **#15** фрейма `npc_rename` («клик start → следующий фрейм») между
`LClick=1` и переходом кадра вставляются 5 действий формата
`act88("GuardName_N", "<ключ>")`:

```
ЕСЛИ  клик по start / стоп-анимация / LClick==0
ТО    звук 'rumble';  LClick = 1
ТО    act88("GuardName_1", "Cell Key")
ТО    act88("GuardName_2", "Utility Key")
ТО    act88("GuardName_3", "Entrance Key")
ТО    act88("GuardName_4", "Staff Key")
ТО    act88("GuardName_5", "Work Key")
ТО    переход в кадр 5 (load → game)
```

Это перекрывает и рандомайз, и ручные переименования, и работает для DLC
(та же группа обслуживает `escapeteam`/`DTAF`/`SS`/`CCL`, флаги которых
ставятся во фрейме `npc_rename` по имени карты).

Декодирование действия (проверено побайтовым совпадением с встроенным донором
`act88("UsedNames","")` группы #25):

```
action header: u16 size(с себя) i16 objType=36 i16 num=88 u16 objInfo(=3 в npc_rename)
               i16 list=0 i8 flags=0 i8 other=0 u8 nparams=2 u8 defType=0
params:        [u16 size(с себя) 0x2d=StringExprParam][u16 cmp=0]
               expression: otype=-1 num=3 (строковый литерал) esize=6+len(UTF-16LE+\0)
               terminator выражений: 0x00000000
```

Пересборка: группа получает новый отрицательный i16-размер; поля `ERes`/`ERev`
растут на дельту; подчанк 13117 шифруется заново (zlib level 9, как в оригинале);
размеры в потоке чанков PE-оверлея пересчитываются (см. `tools/te1_guardkeys.py`,
изначально — `tools/te1_patch.py` из TE1Modding).

## 4. Проверка результата (что гарантирует патчер)

`te1_guardkeys.py patch` после записи exe перечитывает его и проверяет:

1. события `npc_rename` парсятся полностью (`consumed == total`);
2. число групп не изменилось, группа #15 содержит ровно наши 5 `act88`;
3. сборка `act88` нашим конструктором **байт-в-байт совпадает** с игровым
   донором из той же сборки exe;
4. воспроизведение исходной группы нашим `group_bytes()` до правки —
   байт-в-байт (иначе сборка отклоняется заранее);
5. всё до и после целевой группы в событиях идентично; все остальные чанки
   exe (остальные фреймы, ресурсы) побайтово совпадают с оригиналом;
6. повторный `patch` на уже пропатченном файле честно отказывает (exit 4).

Проверено на сборках: **eur (Steam), rus, pol** — результат идентичен
(`TheEscapists.exe.txt` старого однофреймового лаунчера не поддерживается).

## 5. Ограничения и замечания

- **Старые сейвы** — в них имя уже записано, они остаются со старыми именами;
  мод действует на новые партии (и на все сохранения, сделанные после него).
- Офицеров #6+ и вышечных снайперов мод не трогает (ключей нет).
- Туториал — отдельный фрейм, не затронут.
- Обновление игры или «проверка целостности» в Steam вернёт оригинальный exe.
- Распространять нужно **патчер**, а не пропатченный exe (см. замечание о
  легальности в `MODDING_THE_ESCAPISTS.md` из архива).

## 6. Как повторить исследование самому

```bash
# распаковать архивы репозитория и пользоваться оригинальным тулкитом:
unzip TE1ModdingPart1.zip -d part1
python3 part1/tools/te1_frames.py list part1/exe/game/TheEscapists_eur.exe.txt
python3 part1/tools/te1_events.py dump part1/exe/game/TheEscapists_eur.exe.txt \
    --frame npc_rename -o work/npc_rename.txt
# ключи: grep "assign_keys" part1/dumps/game_events.txt
# офицеры: grep "GuardName_\|create_guards" part1/dumps/game_events.txt
```
