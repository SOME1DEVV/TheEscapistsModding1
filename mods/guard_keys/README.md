# Мод «Guard Key Names» — офицеры названы по цвету ключа

**The Escapists 1 (PC / Steam, движок Clickteam Fusion 2.5)**

В каждой тюрьме первые пять офицеров всегда носят одни и те же ключи
(проверено по байткоду игры: фрейм `game`, группа `assign_keys`
раздаёт `NPC_1..5_Inv_1` одинаково на всех картах):

| Офицер | Ключ (предмет) | Двери | После мода его зовут |
|:-:|---|---:|---|
| **#1** | Cell Key (ID 0) | жёлтые | `Officer Cell Key` |
| **#2** | Utility Key (ID 7) | оранжевые | `Officer Utility Key` |
| **#3** | Entrance Key (ID 6) | фиолетовые | `Officer Entrance Key` |
| **#4** | Staff Key (ID 1) | **красные** | `Officer Staff Key` |
| **#5** | Work Key (ID 43) | зелёные | `Officer Work Key` |

Да, «четвёртый всегда с красным ключом» — это именно офицер #4 (Staff Key).
Теперь не надо запоминать и выбивать вслепую: журнал персонажей и подписи под
офицерами сразу говорят, кого валить.

Работает на всех тюрьмах, включая DLC (`irongate`, `escapeteam`, `DTAF`, `SS`,
`CCL`), т.к. привязка одинакова везде. Офицеры #6 и дальше ключей не носят —
их имена мод не трогает.

## Установка через лаунчер (рекомендуется)

1. Положи `TE1_Mod_Launcher.bat` (из корня этого репозитория) в папку игры,
   рядом с `TheEscapists.exe`, и запусти двойным кликом.
2. Меню → `2. Mod Workshop` → `3. Guard Key Names` → `1. Install`.
   Лаунчер сам пропатчит **настоящий exe игры** (`theescapists_eur/rus/pol.exe`;
   маленький `TheEscapists.exe` — только кнопка «Play», его он корректно
   пропустит) и сделает бэкап в `mods\original\exe\`.
3. Запускай игру пунктом `1. Launch Game With Mods`. Патч проверяется перед
   каждым запуском: если Steam обновил/восстановил exe, мод сам накатится
   заново. Запуск прямо из Steam тоже работает — патч сидит в exe.
4. Удаление: то же меню → `1. Uninstall` — бэкап вернётся на место.

## Установка вручную через INSTALL.bat (Windows)

1. Закрой игру. Найди `TheEscapists.exe` (Steam → Управление →
   «Посмотреть локальные файлы»).
2. Рядом положи папку мода. Нужен Python 3
   (`winget install Python.Python.3` или с python.org, галка «Add to PATH»).
3. В папке мода запусти:

   ```bat
   INSTALL.bat "C:\Program Files (x86)\Steam\steamapps\common\The Escapists\TheEscapists.exe"
   ```

   (или перетащи `TheEscapists.exe` прямо на `INSTALL.bat`).
4. Появится файл `TheEscapists_guardkeys.exe` рядом с оригиналом.
   Переименуй оригинал в `TheEscapists_backup.exe`, а
   `TheEscapists_guardkeys.exe` — в `TheEscapists.exe`.
5. Играй. В стартовом экране «население тюрьмы» офицеры уже будут подписаны
   ключами. **Новая карта/новая тюрьма — с новыми именами; имена сохраняются
   вместе с записью игры.**

Удаление/откат: верни `TheEscapists_backup.exe` на место, либо Steam →
«Проверить целостность файлов игры».

## Тоже самое вручную (любая ОС)

```bash
python mods/guard_keys/te1_guardkeys.py check  /path/to/TheEscapists.exe
python mods/guard_keys/te1_guardkeys.py patch  /path/to/TheEscapists.exe \
       -o /path/to/TheEscapists_guardkeys.exe
```

`check` показывает таблицу ключей, находит нужную группу событий и говорит,
поддерживается ли сборка и не установлен ли мод уже. `patch` после записи
глубоко себя проверяет: события парсятся целиком, все остальные группы и
фреймы побайтово идентичны, созданные действия совпадают с кодировкой
самой игры (сравнение с встроенным донором).

Если патчер пишет «сборка не поддерживается (фрейм npc_rename не найден)» —
ты скорее всего взял маленький запускатель `TheEscapists.exe` (~2,4 МБ,
только кнопка «Play»). Укажи настоящую игру: `theescapists_eur.exe` /
`theescapists_rus.exe` / `theescapists_pol.exe` (~8 МБ) в той же папке.
Лаунчер (способ выше) делает это сам.

Свои имена (ровно 5, через запятую):

```bash
python mods/guard_keys/te1_guardkeys.py patch TheEscapists.exe -o out.exe \
    --names "Cell Key,Utility Key,Entrance Key,Staff Key,Work Key"
```

## Что мод НЕ делает

- **Старые сейвы остаются со старыми именами** (имена хранятся в `save.dat`).
  Мод действует на новые партии; сделанные после установки сейвы — уже ключевые.
- Офицеров можно вручную переименовать на стартовом экране — при нажатии
  «start» мод всё равно вернёт ключевые имена.
- Офицеры #6+ (в крупных тюрьмах) и вышки — без изменений: ключей нет.
- Обучение (tutorial) — отдельный фрейм, мод его не трогает.

## Техника (кратко)

Имена генерирует фрейм `npc_rename` (`cop_loop` → переменные `GuardName_1..N`).
Перед переходом в игру (клик «start») мод дописывает пять действий
`act88("GuardName_N", "<имя ключа>")` в ту же группу событий прямо в exe.
Подробный разбор — [`docs/GUARD_KEY_MOD.md`](../../docs/GUARD_KEY_MOD.md).

Поддерживаются сборки: **eur/steam, rus, pol**. Старые лаунчер-сборки
(один фрейм) — нет; `check` честно скажет.
